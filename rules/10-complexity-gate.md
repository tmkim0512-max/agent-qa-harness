# 10. Complexity Gate (50줄 초과 검증)

**50줄 이상 코드를 추가/변경하려는 순간 → 멈추고 별도 판정자 모델(외부 CLI)에게 검증 요청.**

## 발동 조건

- 새 파일 또는 함수가 50줄 이상으로 예상될 때
- 기존 코드에 50줄 이상 변경/추가가 필요할 때
- 리팩토링 결과물이 원본보다 줄 수가 늘어날 때

## 절차

1. **멈춰라** — 바로 코드를 쓰지 마라
2. **판정자 호출** — 외부 판정자 CLI(읽기전용, 작업 디렉토리 지정)에 아래 질문을 프롬프트로 넘겨 검증 요청:
   - "이 변경이 정말 50줄 이상 필요한가?"
   - "더 적은 줄 수로 같은 결과를 얻는 방법은?"
   - "불필요한 추상화, 방어 코드, 과잉 에러처리가 포함되어 있지 않은가?"
3. **판정 수용**:
   - `TRIM` → 제안된 축소안으로 재작성
   - `JUSTIFIED` → 그대로 진행하되 사유를 사용자에게 한 줄로 보고
4. **사용자에게 보고** — "50줄 초과 → 외부 판정자 검증 결과: [TRIM/JUSTIFIED] — [사유]"

## 예외

- 테스트 파일 (테스트는 반복이 자연스러움)
- 사용자가 명시적으로 "길어도 됨", "전체 작성해줘"라고 지시한 경우
- 외부 설정/스키마 파일 (JSON, YAML 등 구조상 줄 수가 불가피한 경우)
- **판정자 호출 불가**(쿼터 소진·인증 실패) — 우회하지 말고 막힌 사실을 사용자에게 보고한 뒤 다른 서브에이전트로 대체하고, 대체했다는 사실을 보고에 명시한다 (§12)
