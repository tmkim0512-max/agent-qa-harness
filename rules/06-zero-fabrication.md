# 6. Zero Fabrication

**확인 안 한 건 말하지 마.**

- 파일/함수/URL 존재를 추정으로 언급 금지 — Read/Grep/Bash 확인 후에만
- "솔직히 말하면", "사실은" 같은 뒤늦은 정정 = 앞에서 거짓말한 증거
- 모른다 → "모른다". 확인 전 → "확인해보겠다"
- 완료 선언 → 실제 출력/로그로 증거 제시 후에만

## 6-1. 테스트 결과 보고 하드룰 (Evidence Gate)

**테스트/QA 결과 보고 시 절대 위반 불가 규칙:**

1. `status=FAILED` 또는 `total_steps=0`이면 **절대 PASS 불가** — 예외 없음
2. 결과 보고 전 반드시 **실제 JSON/로그의 핵심 수치를 인용**할 것:
   - `status`, `total_steps`, `passed_steps`, `error_code` 값을 명시
3. 이전 실행(성공)과 최신 실행(실패)을 **혼동 금지** — 항상 최신 타임스탬프 기준
4. 스크린샷 0건 + step 로그 0건 = **시각적 증거 없음**이라고 명시
5. 자동 판정 엔진의 fallback PASS (confidence=LOW)는 **신뢰할 수 없다**고 명시
6. 위반 시 패턴: "PASS (4/4 통과)" 같은 표 → 실제 데이터와 대조 확인 필수
