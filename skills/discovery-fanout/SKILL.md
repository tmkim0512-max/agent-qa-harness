# discovery-fanout — 발견 recall 끌어올리기

> **원리:** 발견은 recall 문제다. 한 번의 탐색이 놓치는 걸 여러 번·여러 각도가 합집합으로 메운다.
> 하지만 *무엇이 진짜인지 고르는 판단*은 모델 천장에 묶인다 → 적대적 검증으로 거짓양성을 깎되,
> 천장 자체는 못 올린다. 그래서 **객관 검증이 가능한 발견에만** 쓴다.
> (배경: 상위·하위 모델 비교에서 "절차는 이전되나 깊이는 이전 안 됨". 이 스킬은 절차 쪽만 극대화.)

## §0. 정직성 게이트 — 먼저 이걸 판별하라 (비협상)

작업이 둘 중 어느 쪽인지 먼저 분류한다:

- ✅ **검증 가능한 발견** (오라클 있음): 버그, 보안 결함, 엣지/경계 케이스, 스펙·계약 위반,
  데드코드, 테스트 갭, 회귀, 리소스 누수. → **fan-out 진행.**
- 🔴 **판단·취향 영역** (오라클 없음): "더 우아한 설계?", 열린 창작 품질, 네이밍 센스,
  "이게 좋은가". → **fan-out 하지 마라.** 후보 50개를 뽑아도 셀렉터가 같은 모델이라
  피크 품질이 안 오른다. 사용자에게 한 줄로 고지하라:
  > "이건 검증 오라클이 없는 판단 영역이라 fan-out 실익이 없습니다(모델 천장).
  >  `/effort xhigh` 또는 더 강한 모델/사람 검토로 가는 게 맞습니다."
  그리고 §7로 escalate. 억지로 fan-out 하지 않는다.

애매하면 AskUserQuestion으로 "검증 기준이 뭔가요?(테스트 통과? 재현? 사람 판단?)"를 물어 분류한다.

## §0.5. 검증 강령 — 위반 시 그 항목은 "생존"에서 무효 (Hard Rules, 비협상)

모든 발견·검증 에이전트는 아래를 절대 규칙으로 따른다. 하나라도 어기면 그 항목은 §6 보고의
"생존"에 올릴 수 없다. 철저함은 항목 수가 아니라 **각 항목이 이 강령을 통과했는가**로 측정한다.

1. **인용 없으면 발견 아님** — 모든 주장은 실제 코드를 `file:line`으로 직접 인용해 뒷받침한다.
   인용으로 못 받치면 보고 금지(폐기). 읽지 않은 줄을 인용하지 마라.
2. **추측 금지** — "아마 / ~일 수도 / ~로 보임 / ~할 것 같다 / 의심됨"은 발견이 **아니다**.
   재현 경로도 로직 추적도 없는 의심은 §6 "미검증" 버킷에만 넣고 "생존"에서 제외한다.
3. **재현 또는 강등** — "진짜(real)"로 분류하려면 (a) 결함을 트리거하는 구체적 입력/호출 경로,
   또는 (b) 줄 단위 로직 추적 중 하나가 반드시 있어야 한다. 둘 다 없으면 자동 "미검증" 강등.
4. **냉정 — 칭찬·완곡·격려 금지** — "잘 짜였다 / 대체로 괜찮다" 류 평가 문장 금지.
   결함과 근거만 중립적으로 기술한다. 사용자 비위를 맞추려 신뢰도를 올리지 않는다.
5. **상향 반올림 금지** — "철저해 보이려고" 심각도·신뢰도를 부풀리지 마라. 의심스러우면 **낮춘다**.
6. **검증자는 독립 재확인** — 발견자의 말을 믿지 말고 인용된 `file:line`을 **직접 다시 읽어** 확인한다.
   줄을 못 읽었거나 내용이 다르면 즉시 "반박됨".
7. **모름은 모름** — 확인 못 한 것은 "확인 못 함"이라 적는다. 빈칸을 추론으로 메우지 않는다.

## §1. 렌즈 선정 — N개 *서로 다른* 각도 (동일 N개 금지)

각 렌즈는 다른 실패 양식을 본다. 작업에 맞게 3~4개를 고른다(기본). 코드 발견용 카탈로그:

| 렌즈 | 보는 것 |
|---|---|
| correctness | 로직 오류, off-by-one, 잘못된 조건/분기 |
| security | 인젝션, 인증·권한, 비밀노출, 안전하지 않은 역직렬화 |
| boundary | null/빈값/최대치/유니코드/타임존 등 엣지 입력 |
| concurrency/state | 경쟁상태, 재진입, 공유 가변상태, 순서 의존 |
| contract/API | 시그니처·반환·예외 계약 위반, 호출측 가정 깨짐 |
| error-handling | silent failure, 광범위 catch, 누락된 실패 경로 |
| resource/perf | 누수, N+1, 불필요 재계산, 미해제 핸들 |

코드가 아니면(문서/스펙/데이터) 그 도메인의 실패 양식으로 렌즈를 재구성한다.

## §2. Fan-out 실행

선택한 렌즈마다 에이전트 1개를 **한 메시지에서 동시에** 띄운다(병렬). 각 에이전트 프롬프트:

```
역할: 당신은 [렌즈명] 전문 회의론자다.
대상: <파일/디렉터리/diff 범위>
임무: 이 렌즈로만 결함 후보를 찾아라. 다른 렌즈는 무시.
출력(후보별): { file:line, 한 줄 주장, 재현/근거, 신뢰도(상/중/하), 렌즈 }
규칙: §0.5 검증 강령 전부 준수. 추측 금지 — file:line으로 코드를 인용해 뒷받침할 수 있는 것만.
      재현 경로나 로직 추적이 없는 의심은 "미검증"으로 표기(생존 아님).
      못 찾으면 빈 목록 — 억지로 채우지 마라.
```

기본 에이전트 타입은 범용/탐색 계열. 코드면 `security-reviewer`·`code-reviewer`·`debugger`를
렌즈에 맞춰 섞어도 된다.

## §3. Dedup

모든 렌즈의 후보를 모아 **file:line + 의미**로 병합. 같은 결함을 두 렌즈가 잡으면 1건으로 합치되
"2개 렌즈가 독립 발견" 사실은 신뢰 신호로 남긴다.

## §4. 적대적 검증 (거짓양성 제거)

dedup된 후보마다 **독립 검증 에이전트**를 띄워 *반박*을 시도한다:

```
역할: 당신은 이 주장을 무너뜨리려는 검증자다. §0.5 검증 강령을 적용한다.
주장: "<후보>" @ <file:line>
임무: 인용된 file:line을 직접 다시 읽어라(발견자 말 신뢰 금지). 줄을 못 읽거나 내용이 다르면 즉시 "반박됨".
      읽은 코드로 이게 진짜 결함인지 반증하라.
      불확실하면 기본값은 "반증됨(거짓양성)"이다 — 재현/추적 근거로 확신할 때만 "진짜".
출력: { verdict: real|refuted, 근거(file:line 인용), 신뢰도 }
```

- 기본: 후보당 검증자 1명. **과반 반박 → 폐기.**
- "전수/comprehensive/철저히" 신호 시: 검증자 3명(서로 다른 렌즈: 정확성/보안/재현),
  2명 이상 반박 시 폐기.

## §5. 비용 가드 (silent truncation 금지)

- 시작 전 **에이전트 수를 사용자에게 1줄 고지**: "렌즈 N개 + 검증 M명 = 약 K 에이전트".
- 기본은 작게: 렌즈 3~4 + 검증 1. **확장은 명시 신호("전수/샅샅이/comprehensive")가 있을 때만.**
- 상한에 걸려 범위를 잘랐으면(파일 일부만, 렌즈 일부만) **반드시 보고**에 명시.
  "다 봤다"는 착시 금지 (룰 12 No Silent Failure 정신).
- 대규모(수십 후보·loop-until-dry)가 필요하고 사용자가 워크플로 오케스트레이션에 동의하면,
  Workflow 도구의 fan-out/pipeline 패턴으로 승격한다(그 외엔 Task 병렬로 충분).

## §6. 보고 형식

```
## 생존 (검증 통과 — 인용·재현/추적 근거 있음)
- [상] file:line — 주장 — 근거 — (발견 렌즈 / 검증 verdict)
## 폐기 (검증에서 반박됨)
- file:line — 주장 — 반박 사유
## 미검증 (의심이나 재현·추적 근거 없음 — 생존 아님, 추측으로 단정 금지)
- file:line — 무엇이 의심되는지 — 왜 확정 못 했는지
## 커버리지
- 실행 렌즈: [...]  / 검증 강도: 1 or 3
- 다루지 않은 범위: <명시, 없으면 "전 범위">
```

생존 0건이면 "이 렌즈들로는 결함 없음"이라고 정직히 보고 — 억지 결과 만들지 마라.

## §7. 천장에 닿으면 (escalate)

생존이 빈약하거나 §0에서 판단 영역으로 분류됐으면, fan-out을 더 돌리지 말고:
(1) `/effort xhigh` 권유 → 현재 모델을 자기 천장까지, (2) 그래도 부족하면 더 강한 모델/사람,
(3) 한계를 정직히 보고하고 사람이 개입할 지점을 지목. 하네스로 능력 천장은 못 넘는다.
